## What dhnt is {#what}

dhnt is a language and a system for turning the computers you already own
into one coherent, self-hostable, agent-operable mesh: pooled models and
durable agent fleets on your own machines, with the cloud as a thin,
replaceable relay. The open-source projects are at
[github.com/dhnt](https://github.com/dhnt); the foundation is
[bashy](https://github.com/qiangli/bashy).

## Start {#start}

Install bashy in one line (macOS and Linux; checksum-verified, no sudo):

```sh
curl -fsSL https://dhnt.io/install.sh | sh -s -- --no-service
```

Or ask any AI coding agent to "set up bashy from
https://github.com/qiangli/bashy": the README is the agent skill. bashy is
all you need.
